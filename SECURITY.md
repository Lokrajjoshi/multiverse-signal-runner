# Security Policy

## Supported version

The `main` branch is the active supported version of Multiverse Signal Runner.

## Reporting a concern

Please do not publish sensitive details in a public issue.

For a security concern, contact Lokraj Joshi through [LinkedIn](https://www.linkedin.com/in/lokraj-joshi11/) or open a private GitHub communication channel if available. Include:

- affected page, file, or workflow;
- clear reproduction steps;
- potential impact;
- a minimal proof of concept, when safe.

Please allow time for investigation before public disclosure.

## Scope

This project is a client-side educational game and portfolio artifact. It does not intentionally collect personal information or require secrets to run locally. Never commit passwords, API tokens, private keys, or personal data.

## Safe contribution rules

- Keep GitHub Actions permissions minimal.
- Review workflow changes carefully.
- Do not add third-party scripts without documenting their purpose.
- Run the test suite before submitting changes.

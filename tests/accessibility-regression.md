# Accessibility Regression Checks

## Keyboard navigation

- Confirm the primary game action can be reached using the keyboard.
- Confirm interactive controls have visible focus.
- Confirm keyboard navigation does not trap focus.

## Reduced motion

- Test with reduced-motion enabled.
- Confirm the game remains usable.
- Confirm non-essential animation is reduced or disabled.

## Touch and responsive behavior

- Test at a narrow mobile viewport.
- Confirm controls remain visible and usable.
- Confirm no important action depends only on hover.
- Confirm score and feedback text remain readable.

## Validation result

Record the browser/device tested and any issue found.

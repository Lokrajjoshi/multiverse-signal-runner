# Playtest Checklist

Use this checklist before opening feedback on Signal Runner.

## Mission clarity

- [ ] The objective is understandable within the first few seconds.
- [ ] The player can identify trusted signals and anomalies.
- [ ] Telemetry labels are understandable while playing.
- [ ] Mission completion and failure states are clear.

## Interaction

- [ ] Arrow keys and WASD move the drone.
- [ ] Shift activates boost.
- [ ] Space triggers validation.
- [ ] P pauses and resumes the mission.
- [ ] Touch controls work on a narrow viewport.
- [ ] Focus remains visible when navigating controls by keyboard.

## Quality

- [ ] A collision produces the expected integrity change.
- [ ] Validation affects the intended anomaly.
- [ ] Score, combo, and rank update consistently.
- [ ] Reloading starts a clean mission.
- [ ] Browser console shows no unexpected errors.

## Accessibility

- [ ] Text remains readable at the tested viewport size.
- [ ] Reduced-motion preference is respected.
- [ ] Controls have meaningful labels.
- [ ] Color is not the only signal for an important state.

## Feedback format

When reporting an issue, include:

- browser and version;
- device and operating system;
- viewport size;
- exact steps;
- expected result;
- actual result;
- screenshot or recording when useful.

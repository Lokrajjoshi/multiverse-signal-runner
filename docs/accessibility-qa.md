# Accessibility QA Checklist

## Keyboard Navigation

- [ ] All interactive controls can be reached using Tab.
- [ ] Focus order is logical.
- [ ] Focus indicators are clearly visible.
- [ ] Enter and Space activate controls correctly.
- [ ] Escape closes overlays or menus where applicable.

## Visual Accessibility

- [ ] Text has sufficient contrast.
- [ ] Important information is not communicated by color alone.
- [ ] Text remains readable on mobile screens.
- [ ] Layout does not overflow horizontally.

## Motion and Animation

- [ ] Animations do not prevent navigation.
- [ ] Important content remains understandable without animation.
- [ ] Reduced-motion behavior is available or documented.
- [ ] Cursor and visual effects remain decorative only.

## Content and Controls

- [ ] Buttons and links have clear labels.
- [ ] Images and SVGs have meaningful alternative text where needed.
- [ ] External links are clearly identified.
- [ ] The page title and headings are understandable.

## Browser and Mobile Testing

- [ ] Tested in Chrome.
- [ ] Tested in Edge or Firefox.
- [ ] Tested at mobile width.
- [ ] Tested at desktop width.
- [ ] No broken links or missing assets were found.

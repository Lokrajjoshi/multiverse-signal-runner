# Changelog

All notable changes to Multiverse Signal Runner are recorded here.

## [Unreleased]

- Collect real playtest feedback through structured GitHub issues.
- Evaluate accessibility, telemetry clarity, and mission pacing before the next feature release.

## [1.0.0] — Initial public mission

- Published the playable Signal Runner experience on GitHub Pages.
- Added dependency-free ES modules and Canvas 2D rendering.
- Added deterministic mission, collision, scoring, combo, rank, and validation logic.
- Added live integrity, coverage, insight, signal, and high-score telemetry.
- Added native Node.js tests for the domain engine.
- Added GitHub Actions quality checks and Pages deployment.
- Added responsive keyboard and touch controls.
- Added reduced-motion support and visible interaction feedback.
- Added technical documentation, contribution guidance, and issue templates.
